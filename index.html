How to Play

Celebrity Chain is the ultimate pop-culture word association game!

  • The first player names any celebrity (e.g. Tom Hanks).
  • The next player must name a celebrity whose First Name starts with the First Letter of the previous Last Name.
  • Example: Tom Hanks ➔ Harrison Ford ➔ Frank Sinatra ➔ Scarlett Johansson!
  • Single-name celebrities (Cher, Drake, Rihanna) are allowed — they chain off their own first letter.
  • Each valid celebrity earns +1 Point.
  • You have 20 seconds per turn. Running out of time or submitting an invalid name passes the turn with 0 points.
  • First player to reach the target score wins!
